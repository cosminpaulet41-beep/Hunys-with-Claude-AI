# Hunys with Claude AI

Aplicații și jocuri open source, făcute de Hunys împreună cu Claude AI.
Open source apps and games made by Hunys together with Claude AI.

| Proiect / Project | Ce este / What it is |
|---|---|
| [Tura de Noapte 2](tura-de-noapte-2/) | Joc de groază 3D pentru Android, continuarea Turei de Noapte de pe Nokia E72: trei episoade în Spitalul Universitar. · A 3D horror game for Android, the sequel to Night Shift on the Nokia E72: three episodes in the University Hospital. |
| [Viermele Stelar](viermele-stelar/) | Joc cu viermi în spațiu, în română și engleză. Se joacă din browser, pe telefon sau calculator. · A space worm game in Romanian and English, played in the browser on a phone or computer. |
| [SmartTube Hunys](smarttube-hunys/) | YouTube fără reclame pentru proiector/TV, cu player ca la YouTube, repere, teme și mod de noapte. · Ad-free YouTube for a projector/TV with a YouTube-like player, chapters, themes and night mode. |
| [Pas Volum](pas-volum/) | Tastele de volum ale telecomenzii sar mai multe trepte deodată. · The remote's volume keys jump several steps at once. |
| [Penumbra](penumbra/) | Întunecă ecranul mai mult decât luminozitatea minimă, cu filtru cald, notificare și buton rapid. · Dims the screen below minimum brightness, with a warm filter, notification controls and a Quick Settings tile. |
